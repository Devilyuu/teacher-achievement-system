# 教师试用说明

这是“教师个人成果管理系统”的学院内部试用版。请先用 1 到 2 条成果走完整流程，重点测试填报、上传材料和导出材料包是否顺畅。

## 一、登录系统

1. 打开管理员发给你的访问地址。
2. 输入账号和初始密码。
3. 首次登录后按提示修改密码。

如果打不开页面，请先确认自己和发布系统的电脑在同一局域网内。

## 二、新增成果

1. 点击左侧“新增填报”。
2. 选择年度、大类、小类、申报性质。
3. 填写成果名称、级别、本人角色、申报积分等信息。
4. 如果是过程性工作，请在进展说明中写清楚当前完成情况。
5. 点击保存后进入成果详情页。

提示：系统里的赋分规则仅作填报参考，最终分值和级别认定仍以线下审核为准。

## 三、上传支撑材料

1. 在成果详情页找到材料上传区域。
2. 选择证书、文件、截图、表格或压缩包等支撑材料。
3. 可以为材料填写一个更清楚的名称。
4. 上传后确认材料出现在列表中。

支持的材料格式包括：

```text
pdf、doc、docx、xls、xlsx、png、jpg、jpeg、zip、rar、7z
```

单个文件最大 50 MB。

## 四、查看和修改成果

1. 点击左侧“成果管理”。
2. 按年度查看自己的成果。
3. 可以进入成果详情页继续补材料、替换材料、重命名材料或编辑成果信息。

## 五、导出年度材料包

1. 在“成果管理”选择对应年度。
2. 点击年度导出入口。
3. 在导出确认页核对“本次导出成果”和“待完善成果”。
4. 点击下载个人年度材料包。

下载得到的是 ZIP 压缩包，里面包含：

- 个人项目申报表 Excel。
- 材料目录 Excel。
- 按类别整理好的支撑材料。
- 导出说明文件。

## 六、请重点反馈的问题

试用时请优先反馈以下问题：

- 登录不了。
- 页面打不开。
- 成果保存失败。
- 材料上传失败。
- 导出 ZIP 失败。
- 下载后的 Excel 或材料包内容不对。
- 管理员看不到你已经提交的成果。

反馈时请尽量提供：

- 你的姓名或账号。
- 操作到哪一步。
- 页面截图。
- 成果标题。
- 使用的浏览器。
