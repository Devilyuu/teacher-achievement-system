# 试用发布检查清单

本文用于每次组织学院内部试用前快速确认系统是否可用。当前版本定位为本机/局域网试用版，适合 50 人以内的小范围测试。

## 一、发布前准备

1. 确认电脑和参与测试的同事在同一局域网内。
2. 确认这台电脑试用期间不要关机、休眠或切换网络。
3. 在项目目录运行自检：

```powershell
cd C:\Users\lenovo\Desktop\jixiao\.worktrees\mvp-implementation
.\scripts\check_trial_readiness.ps1
```

4. 启动系统：

```powershell
.\run.ps1
```

5. 记录命令行显示的地址：

```text
本机访问：http://127.0.0.1:8001
局域网访问：http://本机IPv4:8001
```

6. 如果同事打不开局域网地址，优先检查：

- 是否在同一 Wi-Fi 或同一有线网络。
- Windows 防火墙是否允许 Python/uvicorn 在专用网络通信。
- 试用电脑是否正在使用校园网隔离、访客网络或 VPN。
- `.\run.ps1` 窗口是否仍在运行。

## 二、账号准备

1. 管理员先用默认账号登录：

```text
账号：admin
密码：admin123456
```

2. 首次正式试用前建议修改管理员密码。
3. 进入“用户管理”，下载“标准模板”。
4. 用 Excel 填好教师账号、姓名、部门、角色、初始密码。
5. 上传模板并预览，确认无误后导入。
6. 将每位教师的账号、初始密码和访问地址单独发送给本人。

建议初始密码统一设置为临时密码，例如：

```text
teacher2026
```

教师首次登录后系统会要求修改密码。

## 三、教师试用主流程

请让每位老师至少完成一次完整流程：

1. 打开局域网地址并登录。
2. 首次登录后修改密码。
3. 进入“新增填报”，填写 1 条真实或模拟成果。
4. 进入成果详情页，上传 1 份支撑材料。
5. 回到“成果管理”，确认该成果能看到。
6. 进入“导出记录”或成果列表中的年度导出入口。
7. 打开导出确认页，核对“本次导出成果”。
8. 下载个人年度材料包。

## 四、管理员核查主流程

1. 进入“年度汇总”。
2. 选择年度和部门。
3. 查看教师填报数量、材料数量、待完善情况。
4. 下载年度汇总 Excel。
5. 下载年度支撑材料 ZIP。
6. 抽查 1 到 2 位教师的成果详情和材料预览。

## 五、试用反馈收集

建议让老师反馈时尽量包含以下信息：

- 使用的浏览器。
- 访问地址是本机地址还是局域网地址。
- 操作到哪一步出问题。
- 页面截图。
- 成果标题或账号姓名。
- 是否是上传、保存、导出、登录相关问题。

优先收集会阻塞主流程的问题，例如：

- 无法登录。
- 无法保存成果。
- 无法上传材料。
- 无法下载材料包。
- 管理员看不到教师填报。

暂时不优先处理的问题：

- 个别文案不够精致。
- 图标、间距、颜色等非阻塞体验问题。
- 后续才需要的高级统计或审核自动化。

## 六、试用数据位置

当前试用版数据保存在项目目录下：

```text
data/database/app.sqlite3
data/uploads
data/exports
```

系统备份入口在管理员端“系统备份”。正式让较多同事试用前，建议先下载一次系统备份。

## 七、试用期间注意事项

- 不要删除 `data` 目录。
- 不要同时启动多个端口为 8001 的服务。
- 老师上传的材料只用于本次系统试用和线下审核验证。
- 目前最终分值、级别认定、团队分配仍以线下审核为准。
