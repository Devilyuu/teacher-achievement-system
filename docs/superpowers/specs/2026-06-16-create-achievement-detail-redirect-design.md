# 新增成果后进入详情页设计说明

## 背景

教师新增成果后，下一步通常是补充支撑材料。目前保存成功后会回到成果管理列表，老师需要再从列表里找到刚刚创建的成果，流程多了一步。

## 目标

- 教师新增成果保存成功后，直接进入该成果详情页。
- 详情页已有待完善原因提示和材料上传区，能够引导老师继续上传支撑材料。
- 不改变编辑成果后的跳转逻辑，编辑保存后仍回到详情页。
- 不改变成果状态计算、材料上传、年度首页待处理统计等既有逻辑。

## 范围

本次只调整教师端新增成果提交后的跳转目标：

- `POST /achievements` 成功后跳转到 `/achievements/{achievement.id}`。
- 不新增成功提示弹窗。
- 不改变成果列表入口。
- 不改变管理员端任何功能。

## 测试设计

- 修改现有新增成果测试，断言创建成功后响应头 `location` 指向新成果详情页，而不是 `/achievements`。
- 继续请求跳转后的详情页，确认刚创建的成果标题可见。
- 跑教师端相关测试和全量测试，确保列表、详情、材料上传不受影响。

## 验收标准

- 教师点击“新增成果”保存后，浏览器进入该成果详情页。
- 详情页可以继续上传支撑材料。
- 自动化测试通过。
