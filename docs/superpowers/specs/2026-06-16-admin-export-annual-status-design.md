# 管理员汇总导出年度状态设计

## 背景

系统已经支持教师年度确认提交，并在管理员年度汇总页面展示 `未开始 / 整理中 / 已提交 / 已导出`。但管理员导出的 Excel 仍只包含成果数量、可申报数量、待完善数量和材料数量，线下催交时看不到教师年度整理状态，页面信息和离线表格不一致。

## 目标

- 管理员导出的年度汇总 Excel 能看到每位教师的年度整理状态。
- 管理员导出的材料包内置汇总表同步包含年度整理状态。
- 年度状态筛选继续影响导出范围。
- 不改变支撑材料 ZIP 的目录结构。

## 方案

采用最小增强方案：只在 `教师汇总` 工作表增加一列 `年度状态`。

列位置：

- 放在 `账号状态` 之后、`成果数量` 之前。
- 原因是年度状态属于教师年度维度，和账号状态同属教师行摘要信息。

不在以下工作表增加年度状态：

- `成果明细`：该表是一条成果一行，年度状态属于教师年度，不属于单条成果。
- `材料缺失`：该表用于定位缺材料或待完善原因，年度状态放在这里会重复且增加阅读噪音。

## 数据来源

导出构建器继续接收 `AdminSummary`。

`AdminSummary.teachers[*].annual_state.status` 是唯一数据来源，和管理员页面展示保持一致。

## 导出范围

管理员页面的筛选条件已经包含：

- 年度
- 部门
- 教师
- 成果状态
- 年度状态

导出按钮继续携带当前筛选条件。导出 Excel 和材料包都使用同一个 `build_admin_summary()` 结果，因此年度状态筛选会自然影响：

- `教师汇总` 工作表的教师行
- `成果明细` 工作表的成果行
- `材料缺失` 工作表的缺失行
- 材料包中实际打包的支撑材料

## 兼容性

- 现有导出文件仍保持三个工作表：`教师汇总`、`成果明细`、`材料缺失`。
- 只新增一列表头和单元格值，不改变文件名、ZIP 目录结构、材料命名规则。
- 空汇总时仍输出表头，此时 `教师汇总` 也包含 `年度状态` 表头。

## 测试重点

- `教师汇总` 表头包含 `年度状态`。
- 已提交教师导出后，该教师行的年度状态为 `已提交`。
- 空汇总工作簿仍包含 `年度状态` 表头。
- 管理员材料包内置的 `00_年度教师成果汇总.xlsx` 同步包含该列。
- 年度状态筛选导出时，工作簿只包含匹配教师和匹配成果。
