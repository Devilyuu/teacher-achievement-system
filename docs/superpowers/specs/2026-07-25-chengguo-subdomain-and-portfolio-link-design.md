# 成果系统子域名与有谱实验室链接设计

## 1. 目标

为现有教师成果管理系统启用独立访问地址：

`https://chengguo.youpulab.com`

该地址继续使用当前腾讯云服务器上的成果系统服务、数据库、支撑材料和导出记录，不复制部署，不迁移数据。

同时更新有谱实验室作品展示网站，将“教师成果统计系统”从“开发中”调整为“已上线”，首页和作品页均链接到新地址。

## 2. 现有环境

- 主域名：`youpulab.com`
- DNS 服务：腾讯云 DNSPod
- 服务器：`124.221.239.254`
- Web 入口：Nginx
- 成果系统内部地址：`127.0.0.1:8001`
- 有谱实验室静态站点：`/var/www/youpulab`
- 有谱实验室源码：GitHub 私有仓库 `Devilyuu/youpulab`
- 主域名 HTTPS：Let's Encrypt + Certbot

## 3. 域名方案

在 DNSPod 增加一条记录：

| 配置 | 值 |
| --- | --- |
| 主机记录 | `chengguo` |
| 记录类型 | `A` |
| 记录值 | `124.221.239.254` |
| TTL | DNSPod 默认值或 600 秒 |

保留 `youpulab.com`、`www.youpulab.com` 和服务器 IP 的现有访问行为。

## 4. Nginx 与 HTTPS

新增独立 Nginx 站点，仅匹配 `chengguo.youpulab.com`：

- 证书引导阶段的 HTTP 站点仅暴露 `/.well-known/acme-challenge/`，其他路径返回 `404`，不通过 HTTP 暴露应用；证书签发后的最终 HTTP 站点仅保留 ACME 校验并将其他请求跳转到 HTTPS。
- HTTPS 请求反向代理到 `127.0.0.1:8001`。
- 转发 `Host`、客户端 IP、`X-Forwarded-For` 和 `X-Forwarded-Proto`。
- 应用层单次批量上传最多 10 个文件，单文件不超过 50 MB，总大小不超过 500 MB。
- Nginx 默认请求体上限为 64 MB，仅精确路径 `/materials/upload` 放宽到 512 MB，为 500 MB 批量上限预留 multipart 开销；材料替换和其他路由继续使用 64 MB 默认值。
- 代理读写超时保持 300 秒，兼容年度导出和材料打包。

使用 Certbot 为 `chengguo.youpulab.com` 申请独立证书，并纳入现有自动续期机制。变更前后均执行 Nginx 配置检查。

## 5. 成果系统兼容性

成果系统继续运行原有 systemd 服务，不修改数据库路径和上传目录。

需要验证：

- HTTPS 登录和退出正常。
- 登录 Cookie 在反向代理后正常工作。
- 登录后跳转不会回到 IP 地址。
- 静态资源使用相对路径或正确域名。
- 支撑材料上传、预览和下载正常。
- 年度材料导出正常。
- 后续浏览器麦克风可以在该 HTTPS 域名请求授权。

IP 访问暂时保留，便于现有测试人员过渡。新邀请和有谱实验室作品入口统一使用新域名。

## 6. 有谱实验室更新

在 `Devilyuu/youpulab` 的作品数据中修改教师成果项目：

- `status`：由 `dev` 改为 `live`
- `link`：设置为 `https://chengguo.youpulab.com`
- 保留当前名称、简介、图片和标签

现有 Astro 页面会自动将状态显示为“已上线”，并把按钮改为“在线体验”。首页精选作品和作品列表共用同一份数据，因此只需修改一处。

变更推送到 `main` 后，由现有 GitHub Actions 自动构建并部署到 `/var/www/youpulab`。

## 7. 实施顺序

1. 增加 DNSPod A 记录并等待解析生效。
2. 在服务器新增成果子域名 Nginx 配置。
3. 检查并加载 HTTP 配置。
4. 使用 Certbot 签发证书并启用 HTTPS。
5. 验证登录、成果详情、材料和导出流程。
6. 修改有谱实验室作品数据并推送部署。
7. 验证首页和作品页的“在线体验”链接。

如果 DNS 记录无法通过现有工具直接配置，由用户在 DNSPod 控制台完成第 1 步，其余步骤继续自动完成。

## 8. 回退方案

- Nginx 新配置独立于主域名站点和现有默认站点，出现问题时只停用该配置。
- 成果系统服务、数据库和材料目录不做迁移，因此不涉及数据回滚。
- 有谱实验室链接变更可通过 Git 提交回退。
- DNS 记录可删除，不影响主域名和其他项目。

## 9. 验收标准

- `https://chengguo.youpulab.com` 使用有效证书并打开成果系统登录页。
- 登录后关键页面不发生混合内容、重定向或静态资源错误。
- 原 IP 地址和 `www.youpulab.com` 继续正常访问各自服务。
- 有谱实验室首页显示成果系统“已上线”和“在线体验”。
- 有谱实验室作品页显示同样的状态和链接。
- 点击两个入口均在新窗口打开成果系统新域名。
