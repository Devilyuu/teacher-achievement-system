# 支撑材料在线预览设计

## 背景

教师完成支撑材料批量上传和重命名后，需要快速确认材料是否传对。管理员在查看教师年度汇总明细时，也需要快速核对材料内容。当前系统只能下载文件，核对效率偏低。

## 目标

- 教师在成果详情页可以直接预览 PDF 和图片支撑材料。
- 管理员在只读成果详情页可以预览教师已上传的 PDF 和图片支撑材料。
- Word、Excel、压缩包等浏览器不稳定支持的文件继续只提供下载或材料登记信息，不做在线预览。
- 预览不改变材料记录、材料编号、原始文件名或导出逻辑。

## 范围

支持格式：

- `.pdf`
- `.png`
- `.jpg`
- `.jpeg`

权限：

- 教师只能预览本人材料。
- 管理员可以预览任意教师材料，用于线下审核辅助。
- 未登录用户由现有认证机制拦截。

错误处理：

- 材料记录不存在：404。
- 材料文件不存在：404。
- 材料格式不支持预览：404。
- 文件路径不在上传目录内：404，避免异常路径被读取。

## 交互

- 教师成果详情页：在材料操作区增加“预览”图标按钮，仅预览支持的文件显示。
- 管理员成果详情页：材料列表增加“预览”图标按钮，仅预览支持的文件显示。
- 点击后在浏览器中打开原文件，由浏览器原生 PDF/图片能力展示。
