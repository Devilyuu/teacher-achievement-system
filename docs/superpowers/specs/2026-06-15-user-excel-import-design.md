# 用户账号 Excel 批量导入设计

## 目标

为约 50 人规模的二级学院提供轻量批量开户能力，避免管理员逐个创建账号。

## 流程

1. 管理员在用户管理页下载 Excel 模板。
2. 模板包含：用户名、姓名、部门、角色、初始密码。
3. 管理员上传 `.xlsx` 文件，系统仅预检，不立即写入账号。
4. 预检页逐行展示数据与错误；整份文件没有错误时显示“确认导入”。
5. 确认后一次性创建全部账号，新账号首次登录必须修改密码。

## 校验规则

- 空行忽略。
- 用户名、姓名、部门、角色、初始密码均必填。
- 角色支持“教师”“管理员”“teacher”“admin”。
- 初始密码至少 8 个字符。
- Excel 内用户名不能重复。
- 系统已有用户名不能再次导入。
- 不覆盖或更新已有账号。
- 任一行有错误时整批不允许导入。

## 临时数据与安全

预检后将规范化数据写入一次性临时批次文件；密码在写入前完成哈希，临时文件不保存明文密码。确认导入后立即删除批次文件。批次标识使用签名令牌，避免伪造路径。

## 权限

模板下载、预检和确认导入均只允许管理员访问。
