# 成果搜索与筛选设计

日期：2026-06-15

## 目标

帮助教师在历年成果逐渐增多后快速定位记录，尤其是待完善成果和特定类别成果。搜索与筛选只影响成果管理页面的显示结果，不改变个人年度导出的完整数据范围。

## 方案

采用成果列表页顶部集中筛选栏：

- 年度
- 成果状态
- 大类
- 小类
- 综合关键词

所有非空条件取交集，查询结果继续按照绩效大类顺序分组展示。

相比只提供关键词搜索，该方案能快速定位待完善项和具体规则小类；相比单独建设高级搜索页面，集中筛选操作路径更短，符合当前轻量系统定位。

## 搜索范围

综合关键词使用不区分大小写的模糊匹配，搜索：

- 成果名称
- 小类名称
- 当前进展或价值说明
- 备注

关键词首尾空格自动忽略。空关键词不参与过滤。

## 分类联动

- 大类和小类选项来自启用中的绩效规则。
- 未选择大类时，小类下拉显示全部小类。
- 选择大类后，浏览器端立即将小类选项收窄到该大类。
- 如果 URL 中已有不属于所选大类的小类，后端按条件交集返回空结果，页面不会静默修改查询含义。
- 自定义兜底类别与正式类别使用相同筛选方式。

## 状态与年度

- 年度默认当前年度，并保留已有的跨年度查看能力。
- 状态支持：草稿、待完善、可申报、已纳入导出。
- 重置筛选时保留当前所选年度，清除状态、类别、小类和关键词。

## 页面行为

- 筛选条件通过 GET 参数保存在 URL 中，可刷新、收藏或分享给同一账号继续查看。
- 记录数和大类数基于筛选后的结果。
- 有筛选条件但无结果时显示“没有符合条件的成果”，并提供重置按钮。
- 当前年度确实没有任何成果且未使用筛选时，继续显示原有新增成果引导。
- “导出年度材料”始终导出当前年度全部成果，不受页面筛选条件影响，并在按钮旁保持年度语义。

## 查询边界

新增专用查询服务，负责：

- 规范化筛选参数。
- 构建仅限当前登录用户的 SQLAlchemy 查询。
- 应用年度、状态、大类、小类和综合关键词条件。
- 返回筛选后的成果。

路由负责加载筛选选项、分组结果和模板上下文。模板不自行过滤数据库结果。

## 测试

自动测试覆盖：

- 搜索四个目标字段。
- 多条件取交集。
- 只返回当前登录用户的数据。
- 大类、小类和状态筛选。
- URL 中保留筛选值。
- 分类选项来自启用规则。
- 无结果状态与重置链接。
- 导出链接不携带页面筛选条件。

浏览器验收覆盖：

- 大类变化后小类选项联动。
- 查询提交后 URL 和选中值一致。
- 桌面和手机端筛选栏不重叠或产生页面级横向溢出。
