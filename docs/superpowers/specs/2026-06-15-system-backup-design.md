# 系统一键备份设计

日期：2026-06-15

## 目标

管理员可以从系统管理页面一键下载完整备份，用于本机故障、迁移或人工归档。

## 备份范围

备份 ZIP 包含：

- SQLite 数据库的一致性快照。
- `data/uploads` 下全部支撑材料。
- JSON 格式备份清单，记录生成时间、数据库文件、材料文件数量和总字节数。

不包含：

- `data/exports` 中可重新生成的个人包、汇总表和材料包。
- 运行日志、虚拟环境、源代码和测试产生的临时文件。

## 一致性与安全

- 使用 SQLite Backup API 创建快照，不直接复制正在使用的数据库文件。
- 快照和 ZIP 写入 `data/exports/backups/{uuid}/`。
- ZIP 内使用稳定路径 `database/app.sqlite3`、`uploads/...` 和 `backup_manifest.json`。
- 只遍历 `UPLOAD_DIR` 内的普通文件，不跟随目录外路径。
- 备份只允许管理员执行。
- 第一版不提供网页恢复功能，避免误覆盖正在使用的数据；恢复通过停止服务后人工替换完成。

## 页面

- 左侧系统管理增加“系统备份”。
- 页面展示备份内容、恢复说明和“下载完整备份”按钮。
- 页面不展示装饰性统计图，只显示与操作相关的信息。

## 测试

- 普通教师不能访问页面或下载接口。
- ZIP 包含可打开的 SQLite 快照、上传材料和清单。
- 清单文件数量与 ZIP 中材料数量一致。
- 生成备份时不会包含已有导出文件。
- 空上传目录仍可成功生成备份。
