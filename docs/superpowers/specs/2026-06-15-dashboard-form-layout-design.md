# 年度首页与填报页布局优化设计

## 目标

- 年度首页的“最近成果”和“分类分布”在双栏布局中占满各自网格，顶部和底部对齐。
- “分类分布”内部采用纵向弹性布局，使审核提示稳定落在模块底部。
- 新增/编辑成果页面与系统其他主体页面统一使用 `1240px` 最大内容宽度。
- 保持现有移动端单列布局，不产生页面级横向滚动。

## 实现

调整 `app/static/app.css` 与基础模板：

- 覆盖仪表盘网格内面板的全局自动外边距，并让面板高度拉伸。
- 将分类面板设置为纵向弹性容器，审核提示通过自动上边距贴近底部。
- 将 `.achievement-form` 的最大宽度从 `1000px` 调整为 `1240px`。
- 为窄屏网格增加 `minmax(0, 1fr)` 与面板最小宽度约束，防止长文本撑开页面。
- 为应用样式表增加版本参数，确保浏览器立即加载最新布局。

## 验证

- 静态回归测试检查关键布局声明存在。
- 浏览器分别在桌面和手机视口测量容器边界、模块高度及页面横向溢出。
