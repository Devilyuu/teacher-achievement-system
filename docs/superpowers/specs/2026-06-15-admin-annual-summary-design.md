# 管理员年度汇总与批量导出设计

日期：2026-06-15

## 目标

为管理员提供一个面向线下审核准备工作的年度汇总中心。管理员可以查看教师填报和材料准备进度，按条件筛选数据，并导出汇总表、成果明细、材料缺失表和多教师支撑材料包。

本模块不承担线上审核、分值认定、通过或退回操作，也不修改教师原始填报数据。

## 方案选择

### 方案 A：汇总页与导出操作集中在一个页面（采用）

管理员先按年度、部门、教师和成果状态筛选，再查看统计结果或导出当前筛选范围。

优点：

- 查看范围与导出范围保持一致，不易误操作。
- 适合本机和局域网试用，操作路径短。
- 后续增加筛选条件时不需要重构多个页面。

代价：

- 页面承载的信息比单一列表更多，需要控制布局密度。

### 方案 B：统计看板与导出中心分成两个页面

优点是页面职责单一；缺点是筛选条件和状态需要在页面间重复维护，第一版操作成本偏高。

### 方案 C：仅提供导出按钮，不建设汇总页面

开发量最小，但管理员无法在导出前确认教师准备情况，也无法快速发现材料缺失，不满足需求说明书中的汇总管理目标。

## 入口与权限

- 左侧“系统管理”导航增加“年度汇总”入口。
- 路径为 `/admin/summary`。
- 仅管理员角色可以访问页面和所有批量导出接口。
- 普通教师访问时返回 `403`，未登录访问时进入登录流程。

## 筛选口径

筛选条件：

- 年度：必选，默认当前年度。
- 部门：可选，默认全部部门。
- 教师：可选，默认全部教师。
- 成果状态：可选，默认全部状态。

规则：

- 默认包含所选年度内的全部成果，包括“草稿”“待完善”“可申报”和“已纳入导出”。
- “待完善”成果不会被排除，而是在页面和导出文件中明确标记，便于线下催补。
- 部门和教师条件同时存在时取交集。
- 下拉选项来源于当前系统用户和已有成果数据，不硬编码部门。
- 停用账号的历史成果仍纳入汇总，教师行中标记账号状态。

## 页面结构

### 顶部

- 页面标题“年度汇总”。
- 简短说明：统计结果为教师申报数据，最终认定以线下审核为准。
- 当前筛选条件表单。

### 汇总指标

展示当前筛选范围内：

- 教师人数
- 成果数量
- 申报积分合计
- 待完善成果数量
- 支撑材料数量

积分统计直接汇总教师填写的 `claimed_score`，不作为审核认定分。

### 教师准备情况

每位教师一行，显示：

- 姓名
- 部门
- 账号状态
- 成果数量
- 可申报数量
- 待完善数量
- 支撑材料数量
- 申报积分合计

教师行按部门、姓名排序。没有符合当前成果筛选条件的教师不显示。

### 成果明细

显示当前筛选范围内的成果：

- 教师
- 部门
- 年度
- 大类和小类
- 成果名称
- 申报性质
- 申报级别
- 申报积分
- 状态
- 材料数量

成果名称可以进入只读的管理员查看页面。第一阶段不允许管理员编辑教师成果。

## 导出设计

导出操作继承当前页面的年度、部门、教师和成果状态筛选条件。

### 汇总工作簿

文件名示例：

`2026年度教师成果汇总_全部部门.xlsx`

包含三个工作表：

1. `教师汇总`
2. `成果明细`
3. `材料缺失`

`教师汇总`与页面教师准备情况一致。

`成果明细`包含当前筛选范围内全部成果，并保留状态和材料数量。

`材料缺失`仅列出没有支撑材料的成果，或状态为“待完善”的成果，并增加“缺失原因”列。第一版缺失原因由现有状态规则生成，包括：

- 申报信息不完整
- 申报积分未填写或不大于零
- 过程性工作缺少进展说明
- 未上传支撑材料

### 多教师材料包

文件名示例：

`2026年度支撑材料包_全部部门.zip`

结构：

```text
2026年度支撑材料包_全部部门.zip
├─ 00_年度教师成果汇总.xlsx
└─ 01_教师材料/
   ├─ 部门名称/
   │  ├─ 教师姓名/
   │  │  ├─ 01_师德师风及党建思政工作/
   │  │  ├─ 02_教师发展/
   │  │  └─ ...
```

材料文件名包含成果序号、成果名称、材料编号和材料名称。文件夹及文件名统一经过安全清理，避免 Windows 非法字符。

数据库中记录存在但物理文件缺失时：

- 导出过程不中断。
- 文件不会写入 ZIP。
- `材料缺失`工作表中标记“材料文件不存在”。

## 服务边界

新增汇总查询服务，负责：

- 统一应用筛选条件。
- 生成页面指标。
- 生成教师汇总行。
- 生成成果明细行。
- 生成材料缺失原因。

新增管理员导出构建服务，负责：

- 创建汇总工作簿。
- 创建多教师材料 ZIP。
- 复用现有类别排序和安全文件名规则。

路由仅负责参数校验、权限控制、调用服务和返回页面或下载文件。

## 错误处理

- 年度不是合理整数时返回 `422`。
- 教师 ID 不存在或不属于所选部门时，结果为空，不泄露额外数据。
- 没有符合条件的成果时，页面显示空状态；工作簿仍可导出表头。
- 没有材料时，ZIP 仍包含汇总工作簿。
- 导出目录自动创建；生成文件使用唯一或可覆盖的稳定路径，避免不同管理员请求相互写坏文件。

## 测试范围

自动测试至少覆盖：

- 未登录和普通教师不能访问管理员汇总。
- 管理员可以查看全部年度成果及统计指标。
- 年度、部门、教师、状态筛选正确取交集。
- 停用教师的历史成果仍被汇总。
- 汇总工作簿包含三个工作表和正确数据。
- 材料包按部门、教师和类别归档。
- 物理材料缺失不会导致导出失败，并进入缺失统计。
- 导出接口只允许管理员访问。

浏览器验收覆盖：

- 桌面端筛选、指标、教师表和成果表可读。
- 手机宽度不出现横向页面溢出，宽表在表格容器内横向滚动。
- 筛选后页面 URL 保留条件。
- 导出按钮携带当前筛选条件。

## 后续衔接

完成本模块后，下一阶段在教师“成果管理”页面增加搜索和筛选。两处筛选会复用一致的年度、类别和状态参数命名，但管理员汇总继续保留部门和教师条件。
