# 教师成果管理系统原型设计

本目录是独立静态原型，不影响当前 FastAPI 试用系统。

## 设计方向

- 参考风格：借鉴“智能陪练”类后台的浅蓝底、白色模块、蓝紫渐变主按钮、柔和彩色功能卡和右侧信息栏。
- 目标用户：需要反复整理年度业绩清单与支撑材料的高校教师，以及负责账号、规则、导出的管理员。
- 视觉语气：轻量、亲和、智能工作台式，降低“年底填表”的压迫感。
- 布局策略：左侧浅色导航，中间主工作区，右侧改为填报辅助栏，承载待处理事项和轻量分类参考。
- 色彩策略：蓝色作为主识别色，紫色用于智能/引导感，绿色用于完整状态，橙红用于待完善提醒。
- 核心差异点：把“成果、材料、分值、导出”做成年度准备度工作台，老师一眼知道下一步处理什么。

## 覆盖界面

1. 年度工作台
2. 成果库
3. 新增成果填报向导
4. 成果详情与支撑材料
5. 导出中心
6. 管理维护入口

## 本次布局调整

- 年度首页移除与右侧“常用功能”重复的三张快捷功能卡。
- 新增成果页面将填报表单置顶，分类说明放在表单之后，减少左右分栏带来的拥挤感。
- 成果名称和价值说明改为整行输入，筛选栏和填报表单使用独立栅格。
- 年度首页“类别进度”补齐 9 个标准大类，并保留“其他有价值工作（自定义）”兜底类。
- 增加顶部年度切换、首页年度档案状态和导出中心历史材料包，表达 2027 填报后仍可回看并下载 2026 材料。
- 右侧“分类参考”改为折叠式轻量提示，默认聚焦当前示例，避免一次性铺满全部规则。
- 新增成果页面的“当前分类说明”改为类别定位、过程材料、常见支撑、审核提醒四块信息。
- 成果详情页将“完整性检查”改为系统自动生成的“导出前检查”，避免误解为用户手工勾选。
- 赋分区域增加当前小类计分公式、分值上限、申报方式和负责人分配提示。
- 新增“申报级别”字段和级别筛选，支持国家级、省级、市级、校级、学院级等参考赋分口径；审核认定级别和最终分值仍由线下确认。
- 将 Excel 颜色含义转成明确规则字段：个人申报、项目负责人赋分、团队负责人申报并分配。
- 右侧栏从导航入口改为填报辅助区，避免与左侧导航重复。
- 精简材料建议、装饰插画、资源圆环和无交互时间切换，仅保留能支持填报决策的模块。
