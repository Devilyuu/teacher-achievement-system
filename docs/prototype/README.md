# 教师成果管理系统原型设计

本目录是独立静态原型，不影响当前 FastAPI 试用系统。

## 设计方向

- 目标用户：需要反复整理年度业绩清单与支撑材料的高校教师，以及负责账号、规则、导出的管理员。
- 视觉语气：安静、可信、工作台式，避免营销页和复杂审核系统的压迫感。
- 布局策略：左侧稳定导航，右侧以年度工作台为主入口，所有页面围绕“材料是否齐全、能否导出”组织。
- 色彩策略：深青色作为系统识别色，琥珀色用于提醒和规则提示，绿色用于可申报/完整状态。
- 核心差异点：年度材料准备度轨道，把“成果、材料、分值、导出”连成一个清晰流程。

## 覆盖界面

1. 年度工作台
2. 成果库
3. 新增成果填报向导
4. 成果详情与支撑材料
5. 导出中心
6. 管理维护入口
