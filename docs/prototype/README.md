# 教师成果管理系统原型设计

本目录是独立静态原型，不影响当前 FastAPI 试用系统。

## 设计方向

- 参考风格：借鉴“智能陪练”类后台的浅蓝底、白色模块、蓝紫渐变主按钮、柔和彩色功能卡和右侧信息栏。
- 目标用户：需要反复整理年度业绩清单与支撑材料的高校教师，以及负责账号、规则、导出的管理员。
- 视觉语气：轻量、亲和、智能工作台式，降低“年底填表”的压迫感。
- 布局策略：左侧浅色导航，中间主工作区，右侧改为填报辅助栏，承载分类参考、材料建议和待处理事项。
- 色彩策略：蓝色作为主识别色，紫色用于智能/引导感，绿色用于完整状态，橙红用于待完善提醒。
- 核心差异点：把“成果、材料、分值、导出”做成年度准备度工作台，老师一眼知道下一步处理什么。

## 覆盖界面

1. 年度工作台
2. 成果库
3. 新增成果填报向导
4. 成果详情与支撑材料
5. 导出中心
6. 管理维护入口

## 本次布局调整

- 年度首页移除与右侧“常用功能”重复的三张快捷功能卡。
- 新增成果页面改为上方规则提示、下方填报表单，减少左右分栏带来的拥挤感。
- 成果名称和价值说明改为整行输入，筛选栏和填报表单使用独立栅格。
- 新增成果页面加入大类/小类参考，展示适用场景和推荐支撑材料。
- 右侧栏从导航入口改为填报辅助区，避免与左侧导航重复。
- 精简材料建议、装饰插画、资源圆环和无交互时间切换，仅保留能支持填报决策的模块。
