01师德师风及党建思政工作

党建、思政、师德相关荣誉、项目、活动等。

02教师发展

培训进修、双师素质、能力提升、人才称号等。

03教学

课程建设、教学比赛、教材、教改项目等。

04产教融合工作

校企合作、产业学院、实训基地、企业实践等。

05学生工作

班主任、导师、竞赛指导、就业创业指导等。

06科研与社会服务工作

论文、课题、专利、培训服务、技术服务等。

07国际交流与合作

国际项目、境外交流、合作办学、外事活动等。

08育人成效

学生获奖、人才培养质量、毕业生发展成果等；常按获奖级别给出参考分。

09监管类工作

质量管理、督导检查、制度执行、专项监管等。

自其他有价值工作
